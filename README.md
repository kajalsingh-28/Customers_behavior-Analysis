📌 Project Overview

This project analyzes customer shopping behavior using transactional data to identify spending patterns, customer segments, product performance, and subscription impact.

It demonstrates a complete analytics workflow from data cleaning in Python, business analysis in SQL, to interactive dashboards in Power BI, followed by executive reporting and presentation.

📂 Dataset

Records: 3,900 purchases

Features: 18 columns

Key attributes include:

Customer demographics (Age, Gender, Location)

Purchase details (Category, Amount, Shipping Type)

Discounts & promotions

Subscription status

Product review ratings

🛠️ Tech Stack

Python: Pandas, SQLAlchemy

Database: MySQL

Visualization: Power BI

Presentation: Gamma (PPT)

🔄 Project Workflow
1️⃣ Data Preparation (Python)

Loaded and explored data using pandas

Handled missing values using median imputation

Standardized column names

Performed feature engineering:

Age group segmentation

Purchase frequency metrics

Removed redundant fields after validation

Exported cleaned data to MySQL

2️⃣ Data Analysis (SQL)

Answered key business questions such as:

Revenue by gender

High-spending customers using discounts

Top-rated and most-purchased products

Subscription vs non-subscription revenue

Shipping type impact on purchase value

Customer segmentation (New, Returning, Loyal)

Revenue contribution by age group

3️⃣ Data Visualization (Power BI)

Built an interactive dashboard featuring:

Revenue and customer distribution

Product and category performance

Subscription impact

Customer segmentation insights

📊 Reporting & Presentation

Created a structured business insights report

Designed a professional presentation using Gamma, highlighting:

Problem statement

Key findings

Dashboard visuals

Actionable recommendations

💡 Key Business Insights

Subscribers contribute higher average revenue

Express shipping users show higher purchase value

Certain age groups drive majority revenue

Loyal customers significantly impact long-term growth.
